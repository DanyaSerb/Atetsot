# Atetsot
 Выполнил Бральгин Даниил Андреевич
# Описание:
 Программа для поиска GitHub пользователей с функцией редактирования списка избранных и сохранения его в JSON файл
# Как использовать API
Для поиска используется публичный эндпоинт `https://github.com`. Токен не обязателен для небольшого количества запросов.
